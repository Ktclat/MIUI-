# MIUI- 个人学习适配项目

基于使用者本地提供的 MIUI+ 2.5.5.643 和指定版本连接组件，研究适用于较新手机系统的原生互联体验。
重点是直接打开软件、同一 Wi-Fi 下保持连接与文本剪贴板同步，需要时再打开手机画面。

这是非官方的开发预览项目。仓库提供自有 C# 入口、可审阅的本地补丁、构建工具与测试，
**不包含小米原程序、DLL、手机 APK、图标或它们的完整反编译源码**，也不能从这里重新编译小米闭源组件。

## 已有改动

- 从 `MIUI-.exe` 直接进入原生界面，中间诊断窗口仅在显式指定 `--diagnostics` 时打开。
- 常驻 MIUI- 托盘，提供打开连接窗口、打开手机面板、退出并断开连接。
  “打开手机面板”只唤出原生面板；需要控制手机时，再从面板打开手机画面。
- 修复面板已显示却被遮挡时“显示面板”被禁用的问题，以及按钮背景拉伸的白色横条。
- 自有入口、托盘、主窗口标题使用 MIUI-，调整中文字体；第三方权利声明保留。
- 移除已确认的本地隐私政策弹窗和界面入口，不写入同意记录。
- 阻断旧 OneTrack、IDM 报告服务及 PrivacyAuthorization track 的已确认统计队列和上传入口，
  普通运行不再由自有宿主配置详细文件日志。具体范围和剩余数据流见 [数据处理说明](docs/DATA_HANDLING.md)。
- 默认连接后不自动启动手机画面；未打开画面时由原生 Guide 处理文本剪贴板。
- 主屏关闭时发送原生后台模式与音频解除指令，请求停止主屏采集，并保留会话及剪贴板处理。
  重新打开恢复画面，默认静音。本次没有实现独立的投屏音频恢复入口。
- 精简已确认的账号入口和自动账号初始化调用；没有新增扫码登录账号步骤。
- 使用经精确哈希限定的较新 IDM 连接运行库，并保留手机端原有的确认和权限检查。
- 减少启动文件验证的 CPU 和重复读取，仍逐文件完整验证固定 SHA-256。

主屏停止与恢复的具体实现、连接条件及未验证部分见 [原生协议与边界](docs/NATIVE_PROTOCOL.md)。
单独的应用副窗口维持此前隐藏行为，本次节能处理限定主屏；并不承诺全部媒体内存释放。
本项目不宣称完全移除了 MiSSO，也不宣称兼容所有澎湃 OS 版本。

## 编译

Windows x64、.NET Framework 4.x、PowerShell 7 和 Python 3.11+（本地使用 PowerShell 7.6.7）：

```powershell
pwsh -File .\build.ps1
pwsh -File .\test.ps1
```

这会编译自有入口并执行离线测试，不下载或运行小米组件。
完整可运行副本还需要合法获得、与固定清单匹配的本地组件。输入版本、目录和完整命令见
[构建说明](docs/BUILD.md)。脚本生成独立新目录，不覆盖原安装。

## 验证情况

先前原生兼容副本由设备所有者反馈可在小米 15 / 澎湃 OS 3 上连接和控制。
本次关闭、托盘、面板、界面与隐私修改只做静态分析、文件验证和自有源码测试，**尚未在该手机上实测**。
参考手机组件与实际组件并非同一份字节，细节见协议说明。

文件校验基准从约 7.49 秒降至 0.38 秒；这只是启动中的一个环节，
不是完整启动、待机占用或手机耗电数据。测量方法和重跑入口见 [性能说明](docs/PERFORMANCE.md)。
